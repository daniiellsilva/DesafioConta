# 💰 Desafio Conta Bancária

Projeto desenvolvido durante um desafio da **Alura**, utilizando **Java** e conceitos básicos de programação.

A aplicação simula uma conta bancária através do terminal, permitindo ao usuário consultar o saldo, realizar transferências e receber valores.

## 🚀 Funcionalidades

* 👤 Exibição dos dados do cliente
* 💰 Consulta de saldo
* 💸 Transferência de valores
* 💵 Recebimento de valores
* ❌ Validação de saldo para transferências
* 🔄 Menu interativo através do terminal
* 🚪 Opção para finalizar o programa

## 🛠️ Tecnologias utilizadas

* Java
* Scanner
* Estruturas condicionais (`if/else`)
* Estrutura de repetição (`while`)
* Variáveis e tipos de dados
* Entrada e saída de dados pelo terminal

## 📋 Menu

Ao executar o programa, o usuário pode escolher entre:

```text
1 - Consultar saldo
2 - Transferir valor
3 - Receber valor
4 - Finalizar
```

## 🎯 Objetivo

O objetivo do desafio é praticar os fundamentos da linguagem Java, trabalhando com:

* Variáveis
* Operadores matemáticos
* Condições
* Loops
* Entrada de dados
* Manipulação de valores

## 📌 Sobre o desafio

Este projeto foi desenvolvido como parte dos estudos de **Java na Alura**, com foco na prática dos conceitos fundamentais da linguagem.
